# VirtualWorks Internship Tasks

## 1. Password Strength Checker
A Python program that checks the strength of a password based on length, uppercase letters, lowercase letters, numbers, and special characters. It also provides suggestions to improve password security.

## 2. Port Status Checker
A network utility that checks whether a specific port on a host system is open or closed using Python socket programming.

## 3. Email Risk Analyzer
A cybersecurity-based program that scans email content and identifies suspicious patterns such as urgent requests, phishing links, and sensitive information prompts.

## 4. File Protection Utility
A Python application that protects file content by encoding it into a secure format and restores it back when needed using Base64 encoding.

## 5. Login Attempt Control System
A secure login simulation that limits repeated incorrect password attempts and temporarily locks access after multiple failures to prevent unauthorized access.
